# 미건 임대 주택 현황 — 실운영 자동화 시스템

House Rent 스킬 기준으로, 앞서 만든 Claude Artifact 대시보드(가상 데이터·CSV 업로드용)에 이어 **Google Sheets를 원본 DB로 쓰는 실운영 자동화**를 추가로 구축했습니다.

## 이번에 선택하신 구성
- 임차인 알림: **SMS만** (알림톡 미사용)
- 은행 입금: **엑셀 업로드 대사만** (문자 자동수신 없음 → Cloudflare Worker/웹훅 불필요)
- 배포처: **GitHub Pages**

## 폴더 구성
| 파일 | 역할 |
|---|---|
| [`Code.gs`](Code.gs) | Google Apps Script 백엔드. 시트 세팅, 매월 청구, 은행 대사, 미납 판정·SMS, 대표 보고, 주간 리포트, 계약/신고 알림, 대시보드용 API(`doGet`)까지 전부 포함. |
| [`index.html`](index.html) | GitHub Pages로 배포되는 조회용 대시보드. `?api=웹앱URL&token=토큰`을 붙이면 실시간 연동, 없으면 이전과 동일하게 CSV 업로드/가상 데이터 데모로 동작합니다. |
| [`미건_임대주택_데이터양식.csv`](미건_임대주택_데이터양식.csv) | 세대 정보 초기 입력용 CSV 양식. |
| [`사람이_직접_할_일.md`](사람이_직접_할_일.md) | 계정 인증이 필요해 AI가 대신할 수 없는 설정 단계 (Google, 솔라피, 카카오, GitHub). |

## 자동화되는 것
매일 00:10 미납 판정 → 09:00 미납 안내 SMS(월 2회 상한, 09~20시만) → 08:00 대표 아침 보고(카카오 나에게 보내기, 실패 시 SMS 대체) → 08:30 계약만기/전월세신고 알림 → 매주 월요일 08:30 주간 리포트를 GitHub에 커밋. 매월 1일에는 전 세대 청구가 자동 생성됩니다.

## 사람이 계속해야 하는 것
- 은행 거래내역 엑셀을 "은행업로드" 시트에 붙여넣고 대사 실행 (자동 문자수신 연동을 안 하기로 하셨기 때문)
- "확인필요" 입금을 세대에 수동 매칭
- 수리 접수/처리 입력
